About This Project
What CardioPredict AI does and how it was built

I built this to practice taking a trained model and wrapping it in something people could actually use, instead of leaving it in a notebook. It takes a patient's basic details and recent blood work and runs them through a Random Forest model trained on the public Heart Failure Clinical Records dataset (299 patient records, so — small dataset, take the output with a grain of salt).

This is a student project. Please don't use it for anything more serious than curiosity — it's not a diagnostic tool, and it hasn't been validated for clinical use.
